## §1 问题与本轮边界

### 要问的问题（不是「种子会不会翻转判决」）

`basket_nav_01` 产物里有两族数，它们的**种子敏感性完全不同**：

| 族 | 字段 | 是什么 |
|---|---|---|
| **A：达标判决本身** | `verdict_reading` / `tiers[1].cagr` / `tiers[1].mde_as_annual_pct` / `verdict_cases_fired` | 账户净值档的读数、它自己的 MDE、判决文本 |
| **B：「离目标多远」** | `gap_to_target_by_benchmark.*.c_mkt_fraction` / `required_excess_annual` / `per_combo.*.measured_excess_annual` / `measured_over_required` / `measured_abs_over_mde` | 把 A 与「基准年化 `c_mkt`」作差之后得到的一整套分解 |

⇒ 本扫描问的是：**换基准抽样种子时，A 族与 B 族各自动不动。**

### 为什么这个问题值得问（而不是「显然不动」）

`_market_by_day` 的抽样**吃种子**（`benchmark_cohort` → `Random(BENCH_SEED)`），
而 `c_mkt` 就是那批票的年化 ⇒ B 族**按构造吃种子**。
A 族是否吃种子，**不能靠构造推理**（理由见 §3.2，且该推理本身是**结构推理不是实测**）。

## §4 采样

- **`seeds = BENCH_SEED + k`，`k = 0 … 20`（N = 21，`k = 0` 在位）。**
  ⇒ `k = 0` 那一格是**基线复核**：它必须**逐位复现**产物 caliber 的 `equal_weight`，
  否则扫描本身与生产脱钩（守卫会响）。
- 🚨 **不许 `hash(day)` / `hash(code)` 派生种子** —— `PYTHONHASHSEED` 让它**不可复现的
  阴性等于没跑**。
- 🚨 **`daily_map` 全程只建一次**，所有种子共用。
  理由逐字见 §2.3 的 `benchmark_cohort` docstring：`rng.sample` 作用在
  `list(all_codes)` 上，**键顺序由 `daily_map` 的构造方式决定**
  ⇒ 每个种子各建一次 `daily_map` ⇒ 换的不是种子而是「顺序 × 种子」两个量。
- N=21 是**资源约束下的测量规模，不是判据**，因此不受「门槛须由外部锚推导」约束；
  但它**事前写死且不许事后调整**（§8）。
  🚨 **登记为债**：`[BENCH_SEED−20, BENCH_SEED+20]` 之外的邻域**未覆盖**。

## §5 判据

⚠️ **每一条门槛都必须由外部锚推导，不许出现手打字面量。**

### D1（**唯一判决型**）—— `required_excess_annual` 全种正号

```
判据：对全部 k ∈ [0,20]，max_k c_mkt(k) < target
⇒    required_excess_annual(k) = ((1+T)/(1+c_mkt(k)))^(1/yrs) − 1  恒 > 0
```

- `T` = 产物自报 `target`（**不是手打的 20%**）。
- 推导：`(1+c_mkt) < (1+T)` 且指数 `1/yrs > 0` ⇒ 比值 > 1 ⇒ 减 1 > 0。**代数必然**。
- `c_mkt < −1` 时 `1+c_mkt ≤ 0` ⇒ 幂无定义 ⇒ 实现须**拒绝**而非回落
  （`required_excess` 只挡了 `yrs ≤ 0`，见 §7 的登记）。

### D2 —— 符号可定性：**阈值 1 来自 MDE 的定义，不是手打**

```
判据：报告 {|c_mkt(k)| / M_mkt(42)} 的分布，并列出 ≥ 1 的 k
```

- `1` 来自 `judge()` 的第一条（`|c| < M` ⇒ 连符号都定不了）——它是 **MDE 的定义**。
- 🚨🚨 **分母 `M_mkt(42)` 本身是种子 42 的量**（§3.3）
  ⇒ 这是**用 A 配置标定的仪器去量 B**（第 17 种形状 / 第 94 层）。
  ⇒ 所以 D2 **只准出形状陈述**：
  - 全部 `k` 的比值 **≪ 1** ⇒ 可写「在本扫描覆盖的种子上，`c_mkt` 相对
    **种子 42 的** MDE 都远在测量下限之下」；
  - **不得**写成「`c_mkt` 的年化在任何种子下都不可定符号」
    ——分母没跟着 `k` 更新，那句话需要重算 `M_mkt(k)` 才成立。
- **判决方向**：若出现 `|c_mkt(k)| / M_mkt(42) ≥ 1` ⇒ 🚨 种子有可能改变
  「连符号都定不了」这一格 ⇒ 该格结论**必须撤回**并登记为**需重算 `M_mkt(k)`** 的债。

### D3（**纯描述，零判据**）—— 分布报告

落盘 `min / p5 / p25 / 中位 / p75 / p95 / max` 与 `mean`、`spread = max − min`。

🚨 **`spread` 是观测极差，不是总体极差。**
⚠️ **不许**写成「基准年化的可能范围是 `[min, max]`」——
那是把 **N 个观测的极差**说成**总体区间**（第 178 层：无阈值的「一致」等于没有判据）。

### D4 —— 逐位差（不是判据，是**取证**）

对 A 族（§3.2）与 `c_mkt(k=0)`，输出**种子间逐位差**：

| 检查 | 期望 | 非零时怎么办 |
|---|---|---|
| `c_mkt(0)` vs 产物 caliber `equal_weight` | **逐位相同** | 🚨 扫描与生产脱钩 ⇒ **停止**，先查接线 |
| `c_mkt(k)` 跨 `k` 的逐位差 | **非零**（换种子必须换票群） | 若逐位相同 ⇒ 种子被忽略 ⇒ **停止** |
| A 族（判决读数 / 三档 `cagr`）跨 `k` 的逐位差 | 结构上**应为 0** | 非零 ⇒ **如实报告**并归因到浮点重排（§3.2），**不许调容差** |
