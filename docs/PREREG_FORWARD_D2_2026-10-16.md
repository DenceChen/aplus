| 量 | 定义 | 外部锚 / 理由 |

## §3 判决规则 R1–R5（预注册 · 门槛由外部锚推导，不写字面量）

### R1 观测独立性
每个 `pred_date` 算**一个**观测。
⚠️ **重叠警告**：实测 10-15 与 10-16 的涨/跌腿名单**大面积重叠**
⇒ 若某两日的 `entry_date` 相同（同一批 bar），它们的收益**不是独立观测**。
⇒ **R1 的实现按 `entry_date` 分组计数**，不是按 `pred_date`。

### R2 MDE 与 t
`t = mean / (sd(ddof=1) / √n)`；`MDE = 1.96 × sd / √n`。
`1.96` = **双侧 95%**，外部锚（正态近似），**不是**从数据推的。

### R3 判决只用逐日**算术**均值差，**不许**用复合差
复合差 `Π(1+r) − Π(1+m)` 对 n=6 是**非线性**的，且与 `t` 的分母不同源。
⇒ 复合差**只作并排展示**，不进判决。
（理由与 [[a-ratio-whose-two-halves-count-different-things]] 同族：复合差的分子分母不是同一族观测。）

### R4 四档判决（**顺序即判据**，按严厉程度降序）

| 档 | 条件 | 含义 |
|---|---|---|
| `POWERLESS` | `n < 6` 或 `\|c\| / MDE < 1` | **连符号都定不了**（第 160 层） |
| `NOT_MEASURABLE_AT_THIS_N` | `\|c\| / MDE ≥ 1` 但 `CI` 跨 0 | 「测不出」 |
| `NEGATIVE` | `CI` 上界 < 0 | 超额为负 |
| `POSITIVE` | `CI` 下界 > 0 | 超额为正 |

⚠️ **`POWERLESS` 必须在最前**（第 141 层「判决分支顺序本身就是判据」）：
`|c|/MDE < 1` 时若先检 `CI 跨 0`，一个恰好远离 0 的点估计会滑进第二档
⇒ **「测不出」与「符号相反」被合并**，而两者对下一步的动作**相反**。

### R5 🚨 判决**只回答**「超额腿能不能定出符号」，**不许**回答「年化够不够 20%」

理由（**由样本量唯一决定**，不由我选）：
n 个独立观测、t 门槛 2.80 ⇒ 需要 `n ≥ 174` 才可能定符号（回测侧 66 个块的同族账）。
在 n ≪ 174 时把「超额 +0.25%/日」外推成年化是**第 167 层的无源之水**：
实测日均 +0.2541% 外推 244 日得 **+85.9%/年**，而同一 6 天的 `CI` 宽 ±1.99pp
⇒ **外推值比它的不确定度小一个数量级**。
⇒ 产物**必须**同时印出点估计与 CI，**不许**只印点估计。

### §6.3 R4 第二档在**连续采样下**是死分支，而「死」有两种不同的含义

`DEAD_BRANCHES`（生产侧模块常量）= `('NOT_MEASURABLE_AT_THIS_N',)`。
本轮用变异台把它量清楚了：

- **代数上**：`lo = c − MDE`、`hi = c + MDE` 联立给出 `CI 跨 0 ⟺ |c| < MDE`
  ⇒ 第一档整条吃掉 ⇒ `|c|/MDE > 1` 时第二档**结构上接不到任何入参**。
- 🚨 **唯一的例外**：`\|c\|/MDE == 1` **恰好相等**那一个**测度零点**
  （此时 `lo` 或 `hi` 恰好为 `0`，而 `0 > 0` 与 `0 < 0` **都**为假）
  ⇒ 它会落进第二档。**严格不等号 `<` 就是在这里承重的**。
- **实测证据（两侧，取证方式不同，必须分开说）**：
  ① 随机扫描 `tests/test_forward_d2_verdict.py::_reachable_under_builder`
     （`trials=4000`、`seed=20261016`，**测试侧函数**）在原始代码下只返回
     `{POWERLESS, NEGATIVE, POSITIVE}` ⇒ 随机采样采不到第二档；
  ② 变异 `M2`（把 `abs(point) < mde` 放宽成 `<=`）**在 21 条守卫下全绿**
     ⇒ 既有守卫集**结构上看不见 `<` 与 `<=` 之差**。

⇒ **补记结论**：「死分支」的准确含义是「**连续/随机采样下采不到**」，
**不是**「代数上不存在能命中它的入参」。
处置：**不删、不改判据**（R4 第一档逐字写的是 `|c| / MDE < 1`，严格小于），
而是补一条守卫钉住那个测度零点落在**第二档**。

⚠️ ①②量的是**不同的东西**，不可互证：
①量「扫描器能采到什么」，②量「守卫集看不见什么之差」。
①②同时成立才说明「**既有守卫的盲区恰好是这个测度零点**」。

### §6.6 R1 的**结论**与它的**理由**不是同一种资产（补记于 2026-10-17，**不是预注册**）

**§3 R1 写下的事实前提**是「10-15 与 10-16 的名单**大面积重叠**」。

⚠️ **这两天根本不在底稿里**：实测 `verification.parquet` 的 `pred_date`
只有 `10-09 … 10-14`（120 行 = 6 天 × 20 行），
因为该表只收「出场 bar 已存在」的日期 ——
`pred_10-15` / `pred_10-16` 两份名单**已发布**
（`pred_2026-10-15.parquet` 10-15 19:18、`pred_2026-10-16.parquet` 10-16 19:26，
`run_status.json` 10-16 全步 `ok`），但它们的 `exit_date` 是 10-19 / 10-20。
⇒ **D1 没断档**，R1 引用的那两天要等 10-19 那一跑才进底稿。
⇒ 所以「大面积重叠」这个前提**在本仓数据上无法直接验证**；
能验证的是**同一件事的同类形态** —— 哪些天共享同一批 bar。

**实测**（`verification.parquet`，涨腿 59 行，`entry_date = gross_pct − market_pct` 之前的原始名单）：

| `pred_date` | `entry_date` | 代码数 | 与其余各天的 up 名单交集 |
|---|---|---|---|
| 2026-10-09 | **10-12** | 10 | ∩10-10 **0**、∩10-11 **0**、∩10-12 0、∩10-13 0、∩10-14 0 |
| 2026-10-10 | **10-12** | 9 | ∩10-11 **1**（`300019.SZ`），其余 **0** |
| 2026-10-11 | **10-12** | 10 | ∩10-12 **4**、∩10-13 **4**、∩10-09/10-10/10-14 **0** |
| 2026-10-12 | 10-13 | 10 | ∩10-13 **4**、其余 **0** |
| 2026-10-13 | 10-14 | 10 | ∩10-14 **0** |
| 2026-10-14 | 10-15 | 10 | — |

★ **两条必须分开读的实测**：

1. `entry_date == 2026-10-12` 那个块 = **29 行 / 28 个唯一 `code`**
   ⇒ 共享同一批 bar 的三天，**名单几乎不重合**（交集 0 / 1 / 0）。
2. 全表 59 行 / **50 个唯一 code**：`000993.SZ` `001216.SZ` `301190.SZ` `688137.SH`
   各出现 **3 次**、`300019.SZ` 出现 **2 次** ——
   而这 5 只**全部落在 `entry_date` 不同的日子**（10-11/10-12/10-13）。

⇒ 🚨 **在这份数据上，「名单重叠」与「共享 bar」是反向的**：
共享 bar 的三天交集 0~1，**不**共享 bar 的日子交集高达 4/10。
⇒ **R1 那句「重叠 ⇒ 不是独立观测」，在这份数据上的真实机制是「共享 bar」，
而「名单重叠」实测根本不是 `entry_date` 重复的成因。**
⇒ 两个量在两份文档里指的不是同一个东西：
`test_run_day_gate.py` 的「重复名单**污染**」指内容重复，
R1 的「重叠警告」指时间窗重复 —— 实测**后者与前者不同源**。
⇒ **R1 的结论（按 `entry_date` 计数）本节一个字不改**：
结论与理由是两种资产，而理由错了不自动作废结论（第 135 层），
而这里结论另有**外部锚**（下一节石川/Jegadeesh）支持。

#### 对照臂实测（`pred_date` 分组，`role: "sensitivity"`，**不参与判决**）

| 量 | 判决臂（`entry_date`，n=4） | 对照臂（`pred_date`，n=6） |
|---|---|---|
| `n_blocks` | 4 | 6 |
| 均值/块 | +0.715736% | **+0.254079%** |
| sd | 1.792655% | **2.493060%** |
| se | 0.896327% | 1.017788% |
| `t` | 0.798520 | **0.249638** |
| `\|c\|/MDE` | 0.407408 | **0.127367** |
| 判决 | `POWERLESS` | **`POWERLESS`（同一档）** |

★ **方向与预期相反，且相反得厉害**：`t` 从 0.7985 **掉到** 0.2496（**0.31×**）。
⇒ 驱动因素**不是**「重叠虚增 n」（拆开 n 确实从 4 涨到 6），
而是**拆块让块间 sd 涨得比 √n 快**（sd 1.79% → 2.49%，涨 1.39× 而 √n 只涨 1.22×）。
⚠️ 对照臂同时改了两件事（分组键 + 块内腿数不均带来的隐含权重），
但腿数实测 **10/9/10/10/10/10** 近乎相等 ⇒ **权重不是驱动因素**：

#### 这条对照臂真正改变的是什么（而**不是**判决）

1. **「还差多少样本」这个数在两个口径下不是同一个数。**
   `MIN_BLOCKS_FOR_ANY_SIGN = 6` ⇒ 判决臂 `n=4 < 6` 是被**结构闸门**挡住的
   （判决档与统计量无关）；对照臂 `n=6` 恰好**越过**结构闸门，改由 `|c|/MDE < 1` 判。
   ⇒ 两者的 `POWERLESS` **同名、不同因**，而读产物的人只会看到一个词。
2. 🚨 **R1 是两者中较宽松的那一个** ⇒ 「我们低估了自己的证据量」这个辩解
   在这一条上**不成立**（实测 t 反而是判决臂高 3.2×）。
   ⚠️ 与 §167 同族：所需样本 ∝ 1/真SR²，而真 SR 连符号都定不了（`|c|/MDE = 0.41 < 1`）
   ⇒ **任何「还差几倍」的数都预设了 `mean = +0.7157%` 为真**。
3. **书上的外部锚站在 R1 这一侧**：`cn_factor_lines.txt:2700` 引
   Jegadeesh et al. (2019) 用**互不重叠**的历史数据分别做时序回归，
   「指出它们是不相关的，因而能够减少 EIV 问题」
   ⇒ 重叠窗口**不得**当独立观测计数。
   ⇒ 这条支持 R1 的**结论方向**，**不支持**「换成 `pred_date` 能多拿证据」。
