## ① 「变异存活」有四种解释，而输出逐位同形

台子只打 `✅ / ❌`。读到 `❌`（存活）时，**下一个问题永远是「我改的是哪一行」**，
不是「守卫有洞」——四种解释的终端输出完全一样：

| 解释 | 怎么排除 | 本轮发生过 |
|---|---|---|
| 变异是**空操作**（锚点没生效） | 查 `old命中`，台子也会拒收 | ✅ 发生过（D1/D7/D8，见 ③） |
| 变异体**语法非法** | `compile()`，台子 v2 有闸门 | ✅ 发生过（D3/D4/D5 报 SyntaxError，**但那是我自检器的伪阳性**，见 ④） |
| 变异是**等价变异体** | 程序取证：两个实现逐位对照 | ❌ 本轮 D6 **不是**等价变异体 |
| **守卫真的没覆盖到** | 取证后确认行为真的变了而没人红 | ✅ 本轮 D6 就是这一种 |

⇒ 第 165 层的第三个入口：**「变异体写错」与「守卫有洞」输出完全相同**。

## ② D6 存活的全过程（本轮唯一的真发现）

**D6**：`work = work[np.isfinite(work["excess"])]` → `work = work[work["entry_date"].notna()]`
（把「剔掉量不在的行」换成「剔掉日期不在的行」）。

第一次跑：**存活**，`rc=0 / 14 passed`。

### 取证（不是推理）

| 量 | 原实现 | D6 变异 | 变了吗 |
|---|---|---|---|
| `n_windows` | 1 | 1 | — |
| `excess_mean` | `0.016666666666666666` | `0.016666666666666666` | **逐位相同** |
| `n_legs` | **3** | **4** | ✅ 变了 |

⇒ **变异确实生效了**（`n_legs` 变了），所以不是空操作、不是语法问题。

### 为什么既有守卫抓不到

`test_nan_market_pct_does_not_poison_a_whole_window` 断言
`np.isfinite(blocks.iloc[0]["excess_mean"])`，而两个实现的 `excess_mean` **逐位相同**。

根因：`work.groupby(...).agg(mean)` —— **pandas 默认 `skipna=True`**。
⇒ 「部分 NaN 不污染均值」是 **pandas 的默认行为**在守，**不是我们那行过滤在守**。

⇒ 这条守卫的 docstring 声称守的东西，实现上**比它以为的多一层**（第 110 层族：
守卫守住了 A，而我的主张说的是 B）。它不是假绿——它守的命题为真——
只是**那行过滤在部分 NaN 下近乎空操作**。

### `np.isfinite` 那一行**真正**承重的地方

**极端分支**：整窗 `excess` **全**是 NaN ⇒ 剔光 ⇒ `work.empty` ⇒ **返回空表**
⇒ `measure()` 交出 `stats=None` ⇒ `main()` 响亮拒绝落盘。

删掉过滤 ⇒ 交给 groupby 的是全 NaN ⇒ 得到**一行 `NaN` 均值** ⇒ 而 `NaN != 0` 为真
⇒ **「测不出」与「算坏了」不可区分**（第 9 种形状的变体）。

**而这一支此前零覆盖** ⇒ 补 `test_a_window_with_no_finite_excess_produces_no_number_at_all`。

### 🚨 补这条时我第一次断言写错了层

第一版第二半写 `with pytest.raises(SystemExit): M.measure(frame)` ⇒ **当场红**。
取证发现：**拒绝落盘在 `main()`，`measure()` 只负责算** ⇒ `measure()` 正确地返回
`stats=None` 而不抛。

⇒ 红的原因是**我断言错了层**，不是实现有洞（第 172 层）。
⇒ 改成断言 `out["excess_arm"]["stats"] is None`。
⚠️ **这条补测的判别力不受影响**：D6 台子复跑 `rc=1`，
唯一变红的就是它（见 ② 末的复跑结果）。

### 结论：这是**守卫的洞**，不是变异选错

⇒ 与 `README_net_nav_cost_tiers.md` 里那条等价变异体的处置**恰好相反**：
那里是「换掉那条变异、守卫一个字不动」；
**这里补断言，因为它同时钉住了 D6 与未来同型的删过滤**。
判据不是「变异存活了」，是**「变异是否真的改变了行为」**——
取证说 `n_legs` 变了 ⇒ 它不是等价变异体 ⇒ 洞是真的。

## ③ 锚点必须与**行尾**对齐（本轮第二次栽）

`load_specs` 给每个块补了末尾 `\n`，而匹配是**子串** ⇒ **锚点只在恰好位于行尾时命中**。

第一次跑：D1 / D7 / D8 三条 `old命中=0`，而 D2 / D6 命中——**只因为那两条恰在行尾**。

| 标签 | 源里那行的真实尾部 |
|---|---|
| D1 | `...),` ← **后面还有逗号** |
| D7 | `lowest = ordered.head(half)          # 生产实际发出的那一半` ← 行尾注释 |
| D8 | `MIN_HALF = 2  # 每半至少这么多行，否则这个窗口给不出排序力` ← 行尾注释 |

⇒ **修法：锚点写成整行内容（不含前导缩进）。** 三条改写后 `old命中=1`。

⚠️ 加上 `load_specs` 已有的两条硬限制（锚点首行必须到列 0 / 锚点与变异体首行缩进相同），
本轮 spec 作者实际要守的规则是**四条**。

## ④ 规格自检必须**编译变异后的整份文件**，不是片段

第一次自检报 D3/D4/D5 `SyntaxError` ——**那是我自检器的伪阳性**：
我编译的是**变异体片段**（`.groupby("pred_date", as_index=False)`、
`if "score" not in frame.columns:\n        raise KeyError(`），
而片段常是**语法非法的子串**，**在文件里完全合法**。

⇒ 自检的两行硬要求：

```python
mutated = src.replace(s.old, s.new, 1)
compile(mutated, s.rel, "exec")   # 整份，不是片段
```

⚠️ 且自检**必须调台子自己的 `MH.load_specs`**（第 171 层）：
第一版我手搓了一份「等价」解析器，报告 11/12 锚点失效 ⇒ **那是关于我的脚本的测量**。
字段名是 **`Spec.rel`** 不是 `path`。

## ⑤ 变异体必须**打在用点上**，不是定义点

D4 故意把阈值写成 `stats.get("years", 0.0) < MIN_HALF` 而不是字面量 `6`，
使**只有** `test_the_verdict_functions_cannot_see_years` 里
「判决体不许出现 `years` 字符串」那一半断言触发 ⇒ **归属干净**，
不会同时触发「判决里不许有数值字面量」那条而让归属变模糊。

D8 把 `MIN_HALF = 2` 改成 `0` ⇒ 杀掉的是「无可测窗口必须响亮拒绝」，
**不是**任何关于「2 是对的值」的断言——本仓**没有任何**地方钉 `MIN_HALF == 2`，
因为那个数字的正当性来自「每半至少 2 行才给得出排序力」这条**设计意图**，
不是来自一个外部锚（`MIN_BLOCKS_FOR_ANY_SIGN = 6` 才是）。

## ⑥ 承重的符号约定：**变异 D1 与它同一条断言的另一面**

每窗 `spread = (分数最高的一半).gross − (分数最低的一半).gross`
⇒ **`spread > 0` ⟺ 低分的跌得更多 ⟺ 有排序力**。

⇒ 所以 `verdict_of` **原样可用**，不必改它一行（改它就是在新文件上重犯第 91 层
「跑过数据后换判据臂」）。
⇒ D1（把 spread 取反）被 `test_the_sign_convention_is_measured_on_both_gradients` 杀掉，
而那条守卫**必须测双向梯度**——只测「低分跌更多」的话，D1 存活而它自己看起来绿。
