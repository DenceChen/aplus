## §0 要回答的问题

用户的常设目标是「5 万元 / **年化收益 20%**」。这是**绝对净值**口径。

此前这个目标**从未被对着交付物本身测量过**。但**原因不是缺尺子**——
`aplus/verify.py:402 compounded_stats()` 的 docstring 逐字写着
「对标『年化 20%』的唯一尺子」，且 `aplus/webapp.py:61` 已把它接进 `/api/status`。
缺的只是**落盘产物**：那个读数只活在一次 HTTP 响应的内存里，
没有 sidecar、没有 provenance 章、事后无从核对。

⇒ **本预注册的产物不新造尺子**，它**调用**既有尺子并把读数落成可核对的产物。
禁止在本脚本里重写任何 CAGR/复利公式（第 163 层：禁的是重写量具）。

## §2 MDE（与目标并排印出，第 16 / 160 层）

对日收益序列 `r_1..r_n`，取对数净值标准差 `sd_log = std(log(1+r_i))`。
`log(CAGR+1)` 的标准误 = `sd_log / sqrt(n)`。

```
MDE = 1.96 × sd_log / sqrt(n)      （年化口径，log 近似）
```

| 条件 | 产物允许的措辞 |
|---|---|
| `|cagr − 0.20| > MDE` | 「高于/低于 20%」——**可以说** |
| `|cagr − 0.20| ≤ MDE` | **只能说「测不出符号」** |

⚠️ **这个门槛在看到任何 sigma 之前写定。** 读到的任何数字只允许**新增对照臂**，
不许回头改 MDE 的系数、样本范围或分组（第 91 层）。

## §3 判决规则（六条，逐字）

- **V1**：产物必须**分开**给 `total_return`（事实：这些天实际累计多少）与
  `cagr`（外推），且各自带标签。**禁止只报 `cagr`。**
- **V2**：`n_days < MIN_DAYS_FOR_ANNUALISATION(=2)` ⇒ `cagr` 必须为 `None`，
  且产物必须明写「未年化」。单日样本的外推一律 `None`（`verify.py:459-470` 实测过
  `cagr=-99.90%` 这种数学全对、解读全错的读数）。
- **V3**：产物**必须**并排给出 MDE；当 `|cagr − 0.20| ≤ MDE` 时，
  `verdict_about_20pct` 字段必须**逐字**为 `测不出符号`，
  **不许**输出「达标」或「未达标」。
- **V4**：产物必须显式声明「本读数不预测未来」。`n_days` 天外推出来的年化
  不是年化业绩。
- **V5**：产物必须带 provenance 章，且 `extra` 里必须有
  `source_parquet_sha256`（**当前字节**的 sha256，不是 mtime）。
  第 166 层实测：章盖着一个它没读过的数据根，比没章更坏。
- **V6**：`n_days`、剔除量（`no_data`/`flat`）必须与
  `hit_rate_diagnosis.json` 逐字一致——两个产物读的是同一张底稿，
  对不上就是口径漂移。

## §4 诚实预写：今天大概率会难看

按第 160 层的纪律，**在看数据之前**先写明预期：

- 当前底稿 5 个交易日、单日 σ 已被实测为 **3.44%**（`verify.py:329` 逐字记载，
  日波动 3.44% / 年化 54.6%）。`n=5` 时 `MDE ≈ 1.96 × 0.0344 / sqrt(5) ≈ 3.01%`
  （log 近似，未计复利拖累）。
- ⇒ `|cagr − 0.20| ≤ 3.01%` 的概率极高 ⇒ **V3 很可能命中「测不出符号」**。
- ⇒ **这不算失败。** 这就是这个量在今天的真实读数：
  **5 天观测还不足以分辨「20%」与「其它任何数」。**
  把它包装成「年化 X%，距离 20% 还差 Y」才是第 109 层的错误证据。

⚠️ 即使 V3 命中，产物仍**必须**给出 `total_return`（那是**事实**，不是外推）。

## §5 这个产物**不能**回答的（不许在汇报里含糊掉）

## §7 补记于动手当日（2026-10-16，**读任何组合数据之前**）

### V6 是**错判据**，换成 V6'

**V6 原文**：「`n_days`、剔除量必须与 `hit_rate_diagnosis.json` 逐字一致」。

**为什么它是错的**（第 7 层：比较前先确认是同一个量）：
这**两个数本来就不该相等**，且它们的差是**设计出来的**——

| 量 | 定义 | 出处 |
|---|---|---|
| `trading_days_measured` | `pred_date.nunique()` —— **出名单的天数** | `diagnose_verdicts` |
| `n_days` | 按 `exit_date` 分组、且成分 ≥ `MIN_BASKET` 的**成交窗口桶数** | `daily_portfolio_returns` |

`verify.py:260-264` 的注释逐字写着「按**窗口本身**去重，不是按 `pred_date`」，
且实测 `2026-10-09/10/11` 三次出名单落到**同一个** `10-12→10-13` 窗口
⇒ 5 个预测日对应**更少**的观测日。

⇒ V6 会把「窗口去重生效」这个**正确行为**判成「口径漂移」。
这是第 112 层「判据不可满足的守卫比恒真的更危险」的变体，
但更隐蔽：它**看起来很严格**、像在防漂移，实际上它把两个不同的量绑死。

**V6'（替代）**：
- `0 < n_days ≤ trading_days_measured`（观测窗口桶数不可能超过出名单天数）；
- 两个产物读的是**同一份底稿**——由 **sha256 相等**保证，不由「计数相等」保证；
- 剔除量 `excluded`（`no_data`/`flat`）**必须**与 `hit_rate_diagnosis.json` 逐字相等
  ——这一条**是真同量**（同一个 `df["result"]` 的取值计数），保留。

⚠️ 本节写于**读取任何组合日收益之前**（`compounded_stats` 当时一次都没被调用过），
因此它是**真预注册的修正**，不是事后补判据。

## §8 补记于动手当日（2026-10-16，**第一次跑出 verdict 之后**）

> 🚨 本节是**看到结果之后**写的补记，**不冒充预注册**（第 91 层）。
> 改的是一条**可推导的公式漏因子**，不是为了让结论好看——恰恰相反，
> 改完之后结论从「低于 20%」变成了「测不出符号」，**对策略更不利**。

### §2 的 MDE 漏了年化放大因子 `252`

§2 原文：`MDE = 1.96 × sd_log / sqrt(n)`。

**推导**（在 log 尺度上，尺度与被估量天然一致）：

```
CAGR + 1 = Π(1+r_i)^(252/n)
log(1+CAGR) = (252/n) · Σ log(1+r_i) = 252 · r̄          ← 年化把日均放大 252 倍
Var(log(1+CAGR)) = 252² · Var(r̄) = 252² · sd_log²/n
⇒ se = 252 · sd_log / sqrt(n)
⇒ MDE = 1.96 × 252 × sd_log / sqrt(n)          ← §2 漏了这个 252
```

§2 那条公式是**日均收益率**的 CI，被我当成了**年化外推**的 CI。
两者差一个 `252/1` 的放大因子，而 `n` 越小放大越狠（`√(252/n)` 级别的放大
叠在 252 上 ⇒ `n=3` 时放大约 145 倍）。

### 实测对照（第一次跑出的数，保留作为记录）

| | 值 |
|---|---|
| `n_days` | **3** |
| `sd_log` | 0.005677 |
| `cagr` | −0.5076390487412595 |
| 漏 252 的 MDE | 0.006424 ⇒ 判「低于 20%」 |
| **正确的 MDE** | **1.96 × 252 × 0.005677 / √3 = 1.6186** |
| `|cagr − 0.20|` | 0.7076 **≤ 1.6186** ⇒ **测不出符号** |

⇒ **V3 的正确输出是「测不出符号」。** §4 的预估方向对了（难看），
但预估的量级（3.01%）也漏了 252，且它用的是回测 σ=3.44% 而非实盘 σ=0.57%。

### 新增 V7：外推年数闸门（**MDE 再大也不能给方向**）

即使 MDE 公式修对了，还有第二个漏洞：MDE 只覆盖**抽样误差**，
**不覆盖**「3 天的实现值代表一整年」这个**预测误差**——后者不可量化。

⇒ **V7（补记）**：`years < MIN_YEARS_FOR_DIRECTION_VERDICT` 时，
`verdict_about_20pct` **只能**是 `测不出符号` 或 `样本过短，不给方向`，
**不许**出现「高于/低于」字样，即使 `|cagr−0.20| > MDE`。

阈值定 **`MIN_YEARS_FOR_DIRECTION_VERDICT = 1.0`**（即至少一整年观测）。
理由不是玄学：用户的目标本身就是**一年**的量，
用不到一年的样本去判决一年期目标，是**把不同期的东西比大小**（第 7 层）。
