## 0. 🚨 本实验的目的是**校正口径**，不是**改善结果**

基准不是可选项。它回答「我的钱相对被动投资赚了多少」。
选一个对我们有利的基准，就是自己给自己发信号。

> **硬规则**：无论三个臂算出什么，**不得**因为结果不好看而选回等权基准。
> 理由不是纪律，是**等权全池根本不是一个基准** —— 没有任何被动资金拿得到它。

⚠️ 明确写死：**这不是「哪个基准数字更大」的问题，是「哪个基准是真实可投资的那个」的问题。**
后者已有答案（书），前者与判据无关。

## 1. ★ 关键设计：口径必须**两端一致**，所以是三个臂不是两个

| 臂 | 组合端 | 基准端 | 它测的是什么 |
|---|---|---|---|
| **A（现状）** | top-N **等权** | **等权**全池 | 因子排序 vs 等权池。**今天所有结论都出自这里** |
| **B（只换分母）** | top-N **等权** | **市值加权**全池 | ⚠️ **不是因子 alpha**，主要是「等权 vs 市值加权」的**市值押注** |
| **C（书上口径）** | top-N **市值加权** | **市值加权**全池 | ★ 同口径下的因子增量 —— **这才是本实验要回答的** |

### 为什么必须有 B：它把「市值押注」从「因子 alpha」里剥出来

若只跑 A 和 C，C 的差额里同时混着两样东西：**因子的贡献** 和 **组合等权带来的市值暴露**。
B 就是那个把市值效应单独测出来的一臂。

⇒ 三个数的关系：
```
超额 = 组合端收益 − 基准端收益
A = P_eq  − M_eq
B = P_eq  − M_cap
C = P_cap − M_cap

C − B = (P_cap − M_cap) − (P_eq − M_cap) = P_cap − P_eq
      ⟹ 组合端「市值加权 vs 等权」的差，**不是因子贡献**（方向也与本节原意相反）
B − A = (P_eq − M_cap) − (P_eq − M_eq) = M_eq − M_cap
      ⟹ 基准端「等权 vs 市值加权」的差
```

🚨🚨 **本节原文把 `C − B` 写成「因子贡献」，那是错的，现予撤回。**
原文写「C 的超额 ≈ 因子贡献 + 组合的市值偏离 ⇒ 因子贡献 ≈ C − B」——
**减法的方向反了**：`C − B` 把组合端换成了市值加权，减掉的是**组合权重的效应**；
而 `B` 与 `C` 的**基准端完全相同**（都是 `M_cap`），所以它们的差里**基准一个因子都没有**。

⇒ ★ **同口径下的因子增量就是 `C` 本身**，不是任何两个臂的差。
⇒ 而 `B` 的价值不在「分解」，在它**单独证明了市值押注的量级**：
  `B = 14.99%` 全部是「等权持仓 vs 市值加权基准」，与因子无关。
🚨 **只报 C 不报 B，等于把一个市值赌注包装成因子 alpha** —— 这句仍然成立，
但理由要改成：不是「C 里混了市值偏离」，而是 **B 那一臂揭示了基准口径本身值 8pp/年**。

### 权重定义（此刻写死，不许跑完再改）
- **市值** = `close × a_shares`（**流通 A 股**，不是 `float_shares` ——
  后者含 B 股/H 股，会系统性高估。依据：`TODO_turn_integrity` §0-B）
- 组合端市值加权：对选中的 N 只按 `close × a_shares` 归一化
- 基准端市值加权：对当日可交易池同上
- ⚠️ **每日重新归一化**（K=21 调仓，复权口径变化不得跨期泄漏）

### 🚨 三件必须与判决一起说的事

（`a_shares` 单因子分块 t = **−0.678**，等权基准下显著**跑输**市值）。

⇒ **三个成本模型差 12.4 倍。** ⚠️ 引用净数必须连**本金与名数**一起引，否则就是第 7 种形状。

| 臂 | 毛超额 | 5 万 / N=200 真实净 |

| A | +6.95% | **−43.62%** |
| B | +14.99% | **−35.58%** |

⇒ ★ **三臂在 5 万 / 200 只下全部是深度负值**，且**离 20% 目标不是差几倍，是差一个符号**。

## 2-C. 🚨 本轮一个真缺口：`−8.04pp` **没有不确定度**

`−8.04pp/年` 是本轮**最值得解释**的数字（它等于「基准口径本身值多少钱」），
但**产物只给了点估计，没给 t**：

```
arms[*] 的键： gross_annual_pct / t_blocked / annual_sd_pct / MDE_annual_pct / ...
diagnostics：  a_minus_b = −0.08041381258799685     ← 标量，无 t、无 sd
```

**为什么这个 t 本来应该很大**：三臂**共用同一次抽样**
（`n_days = 1395`、窗口 `2021-01-04→2026-10-09`、`min_basket = 50` 逐位相同），
所以 `A − B = M_eq − M_cap` 是**逐日同一批股票的两种聚合**。
两个高度相关的序列相减，差值的方差**远小于**各自单独的方差
⇒ 差值的 t 应当**显著大于** A 的 1.727 与 B 的 2.291。
⇒ 这就是共同随机数（common random numbers）检验的标准用法，
而本轮**没用**。

⚠️ **当前只能说「点估计为 −8.04」**，
**不能说「等权池确定跑输市值加权池」** —— 后者需要那个 t。

   判据由上面那个 t 定，**看到数字之后不得改**。

## 3. 顺带必须一起报的诊断（**不是判据**）

1. **组合的市值暴露**：组合与基准的流通市值中位数之比（>1 ⇒ 组合偏小盘）
2. **B 臂的分解值**：`C − B`（因子贡献的估计）
3. **规模因子的独立检验**：`a_shares` 本身作为单因子在窗口内的分块 t
   —— 若它自己就显著，则 B 臂的超额大概率不是「因子」而是「市值」
4. ⚠️ 这些**只作解释**，**不得**反过来用于挑臂

## 5. 这个实验**不能**证明什么

- 不能证明前瞻有效（全样本内）
- 不能证明 20%/年可达：⚠️ **本轮跑的是 `basket_n=200`，而「5 万 / N=10 需毛收益 ≥26.41%/年」是 N=10 的数** ——
  两者不是同一个量（第 7 种形状）。本轮 C 臂毛超额 **+12.49%/年** 在**任何**口径下都够不到 26.41%，
  且 N=200 在 5 万本金下**数学上不可交付**（见 §2-A②）
- **无论 C 臂结果如何，资金侧约束（摩擦正下界 4.787%/年）与它无关，仍然成立**
- 🚨 若 C 臂显著，也只说明「同口径下因子有增量」，**不等于**「5 万这个规模赚得到」
  —— 后者要另算，且必须扣掉那个正下界
