## 触发链

1. 陈旧性守卫（`tests/test_width_capital_feasibility.py::test_the_artifact_is_not_older_than_every_consumer_of_it`）

   发现漂移 ⇒ 强制重跑。
2. 重跑把 `widths["10"].gross_annual_pct` 从 `0.0481` 改成 **`0.04673319056259782`**。
3. `width_capital_feasibility.friction_floor(n, rpy) = annual_friction(1e9, …)`
   = **4.787%/年**，即**纯比例费率**，与本金无关。
4. `solve_capital(n, rpy, need)` 在 `need ≤ friction_floor` 时返回 `None`
   ⇒ **N=10 从「有解 16.1 万」变成「无解」**。

## 🚨 但「无解」这个判决只有 −0.021σ

毛超额年化值的抽样标准误：

```
se = sd_年化 × sqrt(244 / n_days) = 0.130664 × sqrt(244/1396) = 5.4627%/年
```

**两条推导路径必须逐位一致**（第 137 层：两份副本之间没有守卫）：

| 路径 | 怎么来的 | 值 |
|---|---|---|
| A | 上面的公式（代数） | 5.4627%/年 |
| B | 产物自报 `t_naive = gross / se` ⇒ `se = gross / t_naive`（`factor_width_mde.py` 的独立实现） | 5.4627%/年 |

⇒ 差 **0.000000pp**，逐位一致。

```
(4.6733% − 4.7870%) / 5.4627% = −0.021σ
```

⚠️ **上一版的「有解 16.1 万」是 `+0.004σ`。**
⇒ **两个相反的判决都在噪声的 5% 以内。** 这不是「重跑推翻了旧结论」，
是「这个结论从来就没有被测量过」。

⚠️⚠️ **我自己当场犯的错，值得记一笔**：
第一遍复算我写的是 `annual_sd_pct / sqrt(n_days)` = 0.3497%/年，
**低估 15.6 倍** —— 那是把**年化** sd 当**日** sd 用（因为 `gross = mean(daily) × 244`）。
若用它算 σ，差距会被读成 −0.33σ，看起来像「勉强有信号」——
**恰好是噪声该有的样子，而一个错的 se 也能造出这个样子。**
⇒ `gross_se_annual()` 因此把两条路径的一致性做成**硬断言**（不一致就 raise）。

## 根因：判决窗口**随数据增长而滑动**，而它本身就是个判决参数

⚠️ 重跑前我以为「同种子 ⇒ 同结果」，**错了**。两次跑的差异不是随机性：

| | 第一次 | 第二次 |
|---|---|---|
| `window` | `[2021-01-01, 2026-10-12]` | `[2021-01-01, 2026-10-14]` |
| `n_days` | **1395** | **1396** |
| `widths["10"].gross_annual_pct` | 0.0481 | 0.04673319 |

⇒ `--start 2021-01-01` 只钉住了**左端**，`end` 跟着 master DB 的最后一天走。
⇒ master DB 每多一个交易日，**判决窗口就多一天，全部毛超额都变**。

⇒ 而 N=10 的判决恰好卡在边界上（−0.021σ）⇒ **窗口多一天就把它从「有解」翻成「无解」**。

⇒ ★ **窗口的右端是一个判决参数，但它从来没有被登记过。**
这与 §7.1 的 150 只抽样是同一族问题：**判决的分母/边界是默认行为，从没被当成参数钉住**。
区别是抽样那次只是**噪声**，这次是**判决本身随日历漂移**。

⚠️ 推论：**任何引用绝对收益数字的结论都有一个有效期**，而本仓此前把
产物当永久有效。⇒ 每次 master DB 更新后，全部下游产物过期。
本次门禁实测：7 条红里 **4 条**是这一族。
