## 0. 🚨 本实验的目的是**校正口径**，不是**改善结果**

基准不是可选项。它回答「我的钱相对被动投资赚了多少」。
选一个对我们有利的基准，就是自己给自己发信号。

> **硬规则**：无论三个臂算出什么，**不得**因为结果不好看而选回等权基准。
> 理由不是纪律，是**等权全池根本不是一个基准** —— 没有任何被动资金拿得到它。

⚠️ 明确写死：**这不是「哪个基准数字更大」的问题，是「哪个基准是真实可投资的那个」的问题。**
后者已有答案（书），前者与判据无关。

## 1. ★ 关键设计：口径必须**两端一致**，所以是三个臂不是两个

| 臂 | 组合端 | 基准端 | 它测的是什么 |
|---|---|---|---|
| **A（现状）** | top-N **等权** | **等权**全池 | 因子排序 vs 等权池。**今天所有结论都出自这里** |
| **B（只换分母）** | top-N **等权** | **市值加权**全池 | ⚠️ **不是因子 alpha**，主要是「等权 vs 市值加权」的**市值押注** |
| **C（书上口径）** | top-N **市值加权** | **市值加权**全池 | ★ 同口径下的因子增量 —— **这才是本实验要回答的** |

### 为什么必须有 B：它把「市值押注」从「因子 alpha」里剥出来

若只跑 A 和 C，C 的差额里同时混着两样东西：**因子的贡献** 和 **组合等权带来的市值暴露**。
B 就是那个把市值效应单独测出来的一臂。

⇒ 三个数的关系（**不是加法恒等式，只是可核对的分解**）：
```
C 的超额 ≈ 因子贡献 + (组合的市值偏离)
B 的超额 ≈ (组合的市值偏离) 为主
⇒ 因子贡献 ≈ C − B   —— 必须真的减出来看，不能只报 C
```
🚨 **只报 C 不报 B，等于把一个市值赌注包装成因子 alpha。**

### 权重定义（此刻写死，不许跑完再改）
- **市值** = `close × a_shares`（**流通 A 股**，不是 `float_shares` ——
  后者含 B 股/H 股，会系统性高估。依据：`TODO_turn_integrity` §0-B）
- 组合端市值加权：对选中的 N 只按 `close × a_shares` 归一化
- 基准端市值加权：对当日可交易池同上
- ⚠️ **每日重新归一化**（K=21 调仓，复权口径变化不得跨期泄漏）

## 2. 🚨 判决分支（看到任何数字之前写死）

主判据落在 **C 臂**（同口径）。B 臂只作分解，不单独出判决。

| 分支 | 条件 | 含义与**动作** |
|---|---|---|
| **`CAP_FACTOR_WORKS`** | C 臂毛超额 **> 0** 且分块 `t ≥ t_crit(1.96)` | 同口径下因子显著。**唯一允许写「因子有效」的分支**（且仍只是全样本内） |
| **`CAP_POSITIVE_NOT_SIG`** | C 臂毛超额 **> 0** 但 `t < 1.96` | 与今天同结论，只是**换到了正确的靶子上**。数字可引用，但**必须**连 t 和臂名一起引 |
| **`CAP_ZERO_OR_NEGATIVE`** | C 臂毛超额 **≤ 0** | 🚨 **A 臂那 6.89% 全部是等权基准造出来的。** 因子前提在本项目就此作废，`factor_width_mde.json` / `placebo_control.json` 降级为「错误基准下的数字」，**不得**再作为有效结论引用 |

⚠️ **A 臂的数字一律不得作为最终结论**，无论它多大。
A 只保留为「我们曾经测的是什么」的记录。

### 🚨 一条不得逾越的规则
**看到 `CAP_ZERO_OR_NEGATIVE` 时，正确动作是如实报告并作废结论**，
**不是**回头去调 `a_shares` 的口径、不是换个窗口重跑、不是改回等权。
这条与 `TODO_placebo_control` §3 的三条同一族。

## 3. 顺带必须一起报的诊断（**不是判据**）

1. **组合的市值暴露**：组合与基准的流通市值中位数之比（>1 ⇒ 组合偏小盘）
2. **B 臂的分解值**：`C − B`（因子贡献的估计）
3. **规模因子的独立检验**：`a_shares` 本身作为单因子在窗口内的分块 t
   —— 若它自己就显著，则 B 臂的超额大概率不是「因子」而是「市值」
4. ⚠️ 这些**只作解释**，**不得**反过来用于挑臂

## 5. 这个实验**不能**证明什么

- 不能证明前瞻有效（全样本内）
- 不能证明 20%/年可达：5 万 / N=10 需要毛收益 **≥26.41%/年**，当前 C 臂大概率仍远低于此
- **无论 C 臂结果如何，资金侧约束（摩擦正下界 4.787%/年）与它无关，仍然成立**
- 🚨 若 C 臂显著，也只说明「同口径下因子有增量」，**不等于**「5 万这个规模赚得到」
  —— 后者要另算，且必须扣掉那个正下界
