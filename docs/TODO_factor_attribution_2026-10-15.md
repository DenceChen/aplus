## 1. 问题

**逐日毛超额能被组合自身的 8 个因子暴露解释多少？哪些因子在稳定地挣钱？**

为什么值得问：当前毛超额 6.78%/年，门槛 26.39%/年，**差 3.9 倍**。
已知的三条路都补不上这个缺口：

- 防守择时：净超额仅 +0.49%/年，**全部年份救回来也只有 +3pp 量级**；
- 降 K 提速：只改换手，**不改收益的上限**；
- 加因子：n=6 时**测不出**加不加有没有用（见上）。

⇒ 剩下唯一没被正面回答过的是：**现有这 8 个因子，组合给它们的权重对不对。**
如果某个因子在样本内稳定为正、而组合暴露不足，那才是数量级上的杠杆。

---

## 2. 模型（写死）

对每个 K 档（k ∈ {5,10,21,42,63}）分别估计：

```
gross_excess_t = α + Σ_{i=1..8} β_i · expo_{i,t} + ε_t        t = 1..1394
```

- **β_i 的解释**：毛超额对该因子暴露的边际敏感度。
  组合按因子打分选股 ⇒ β_i 近似**该因子在这 6 年里的实现溢价**。
- **α 的解释**：8 个因子都解释不掉的那部分。

---

## 3. 判据（写死；**不得在看到结果后调整**）

### 3.1 显著性怎么算 —— **不用临界值表**

2026-10-15 台账第 85 条：我手打的临界值表错了**一格**
（`crit[n-2]` 索引 ⇒ 0.878，正确是 0.8114）。
⇒ **本次不手打任何临界值表，也不依赖 scipy（本仓没装）。**

改用 **wild bootstrap（野自助）**，分布无关，不需要查表：

- 拟合**受限模型** `y = α`（只有截距），得残差 `ê_t`；
- 对 b = 1..B（**B = 2000**，种子 **20261015**）抽 Rademacher 符号 `w_t ∈ {−1,+1}`；
- 构造伪数据 `y*_t = α̂ + ê_t · w_t`，重新拟合全模型，算 `F*_b` 与 `t*_{i,b}`；
- 联合检验 p 值 = `#{F* ≥ F_obs} / B`；单因子 p 值 = `#{|t*| ≥ |t_obs|} / B`。

**为什么野自助而不是 Newey-West**：日频金融收益有自相关，NW 需要选 lag（又一个自由参数）。
野自助在**不给自相关结构加假设**的前提下拿到第一阶有效的 p 值，
代价是它只能证伪「零关系」，不能给出精确的置信区间。**这里要的正是证伪。**

### 3.2 阈值

| 检验 | 阈值 | 为什么是这个数 |
|---|---|---|
| 联合 `H0: β_1..β_8 全为 0` | bootstrap p **< 0.05** | 常规水平 |
| 单因子 `H0: β_i = 0` | bootstrap p **< 0.05/8 = 0.00625** | Bonferroni，**8 个因子** |
| 跨 K 稳健 | 5 档里 **符号一致** | 见 §3.3 |
| 跨子期稳健 | 前后半段 **符号一致**（2021–2023 / 2024–2026） | 见 §3.3 |

### 3.3 ★ 两条一致性要求（防止「多跑几次总能撞上一个显著」）

单看 p 值，5 档 × 8 因子 = 40 次检验，**必然出现几个假的显著**。
所以一个因子要被称为**候选杠杆**，必须同时满足：

1. 主档（k=21）上 Bonferroni 后显著；
2. **5 个 K 档符号全部一致**；
3. **两个子期符号一致**。

⇒ 40 次检验里「显著且三处同号」的，期望假阳性数量 ≈ 0。
**这条比 p 值本身更严，是本设计的主要防线。**

### 3.4 判决分支（写死，避免事后叙事）

| 观测 | 结论 | 下一步 |
|---|---|---|
| 联合检验不显著 | **8 个因子解释不掉逐日毛超额** | 加权/倾斜这条杠杆**不成立**，去查残差里是什么 |
| 联合显著，**没有**因子过 Bonferroni | 收益是「八个因子一起动」，**拆不出单因子** | 只能整体改权重，不能押注单因子 |
| 联合显著，**有**因子三处同号 | 该因子是**候选杠杆**（**不是证明**，见 §4） | 写独立预注册，进前瞻 |
| 联合显著，但三处符号不一致 | **过拟合，不得使用** | 记入「待查线索」，不作为杠杆 |

**α（截距）单独判**：若 α 显著 > 0 且联合也显著，说明**有因子解释不掉的残差收益**。
这份残差**高度可疑**——它就是样本内选股的过拟合残差。
⇒ 预先声明：**α 显著为正时，不把它算作能力，只记为过拟合的度量。**

## 4. ★ 这份实验**不能**证明什么（写死，防止被过度解读）

1. **全样本内**。组合权重就是用这 6 年拟合的。
   β 的绝对值必然偏乐观；**只有符号的一致性有参考价值，量级不可信**。
2. `R²` **几乎必然很高**，因为选股就是按这几个因子打的分。
   ⇒ **R² 高不是发现，是设计的必然结果。** 不拿它当证据。
3. 样本期跨越 2021–2026 的单一市场环境。**一个 regime 里的实现溢价
   不等于它未来的实现溢价。**
4. 候选杠杆要真用，必须走 `docs/` 里既有的**注册即冻结 / 窗口晚于注册日**
   那套流程。**本实验不构成任何前瞻证据。**

## 7. `1 − R²` 的灾难性抵消：两侧一起改

> ⚠️ **本节是 2026-10-15 补记的，不是事前登记。**
> 代码里原先写着「判据预注册在本文 §8」—— **§8 从未存在**，
> 那句注释所声称的登记**当时并不存在**。这属于「注释里的引用从不校验」
> （形状 22）。本节写于动手当日，**不得再被当成「看到结果之前就写死了」**。
> 下面哪些是判据、哪些是实现细节，逐条标出来了。

### 7.1 现象（实测）

`F_obs = (r2/k) / ((1.0 − r2)/(n − k − 1))`。分母 `1.0 − r2` 是**减法**：

| 量 | 实测值 |
|---|---|
| SSE（残差平方和） | `2.57e-27` —— **不是 0** |
| SSE/SST | `≈1e-30` |
| `1.0 − r2` | **恰好 0.0**（float64） |

⇒ R² 落在 1 的 `eps/2 ≈ 1.1e-16` 邻域内，减法就把分母**抵消成 0**。
真正的触发条件不是「R² == 1」，而是 **`SSE/SST < 1.1e-16`** ——
**近乎完美的拟合就足以触发**，而这在真实数据里并不罕见。

⇒ `ZeroDivisionError`。今天的处置是**响亮失败**（带成因、带实测 SSE、
带该去查哪个上游），**不回落到 `inf` 或 `p=0`** ——
因为 `F=inf ⇒ joint_p = 0.0` 会凭空造出一个「极显著」的判决，
`p=1.0` 会凭空造出「没有杠杆」。两者都是形状 16。

### 7.2 为什么不能只改一侧 —— 这是**纪律**，不是技术洁癖

恒等式上 `1 − R² = SSE/SST`。所以分母可以**直接取 SSE**：

```
F = (R²_u/k) / ((1−R²_u)/(n−k−1)) = R²_u · (n−k−1) · SST / (k · SSE_u)
```

但 `F_obs`（观测）与 `F_star`（零分布，`wild_bootstrap`）**必须同口径**：
p 值是 `mean(F_star ≥ F_obs)`，两侧用两把尺子量出来的比较**没有意义**。

⇒ **要么两侧都不改，要么两侧一起改。** 只改一侧 = 用两把尺子量长度。

### 7.3 判决（这一节才是判据，其余是推导）

1. **两侧一起改成 SSE 口径**，不保留 `1.0 − r2` 作为分母。
2. **阈值与判决分支一个字不改**（§3.2 / §3.4 原样）。本项**只换公式**，
   不重新审视「多显著算显著」。
3. **取消后必须显式给出 p 的分辨率下界**：
   B 个重抽 ⇒ 最小的非零 p 是 `1/B`。若 `p == 0`，
   报的是「**p ≤ 1/B**」而不是「p = 0」，更不是「极显著」。
4. **近完美拟合现在会给出一个合法的巨大 F**，这**不是** bug ——
   它意味着 `y` 与因子近乎共线，此时该看的是 §2 的共线性诊断，
   不是 p 值。输出里必须带这句提示。

### 7.4 边界（与形状 19 同族，别当成「修好了」）

改成 SSE 口径**只消掉了数值抵消，没有改变「这段测量可不可信」**：

- 若上游 `y` 与某列因子完全共线，F 依然会爆炸 —— 现在它是**诚实的爆炸**，
  但结论仍然不成立。**判据 4 的提示是本节的安全带，不能省。**
- §0 的口径核实、§4 的「不能证明什么」**一条都不因为本节而放宽**。

### 7.5 守卫（不得省）

- 两侧口径一致：断言 `F_obs` 与 `F_star` 都从 SSE 来（**不是**断言它们相等）；
- 抵消回归测试：造一个近完美拟合，断言**不再抛异常**，且 `F` 为有限正数；
- 判据 4 的提示**在输出里看得见**（子串守卫），防止日后被当成冗余删掉；
- `p == 0` 必须以 `1/B` 的形式出现在输出里。
