## 1. 外部锚（充分性）—— 与实现路径无关，不需公式、不需容差

`required_excess(T, c_mkt, yrs)` 回答的问题是**「若市场腿是 `c_mkt`，账户还差多少超额」**。
那么它必须满足**充分性**：

> 若 `x = required_excess(T, c_mkt, …)`，则账户净值必须**恰好**达标：
>
> ```
> (1 + c_mkt) · (1 + x)  ==  1 + T
> ```

**为什么这是外部锚**：它是**比值口径的定义式**，对「年率 × 年率 = 年率复合」成立，
与本仓用哪个实现路径、写成 `(1+x)**yrs` 还是别的都无关。
它只问一件事：**这个数够不够**。

⚠️ **它与守卫 N9 ① 现在用的那条不是同一条**：
N9 ① 写的是 `(1+got)**y == (1+T)/(1+c_mkt)` —— 那是 `required_excess` **定义的恒真反解**，
任何按该定义写出来的函数都满足 ⇒ 零判别力（第 176 层）。
把 `y` 换成上面那条之后，N9 ① 才第一次**有牙齿**：
带幂式代入得 `(1+cm)·((1+T)/(1+cm))^(1/y)`，只有 `y == 1` 时才等于 `1+T`。

**第二条（同一形式，用于实测侧）**：

> `excess_contribution(cb, cm, …)` 报的「实测超额」`m` 必须满足
> `(1 + cb) == (1 + cm) · (1 + m)`。
> 这条**已经在守**（守卫 V9 杀「比值→相减」），但它当时与带幂实现配套 ⇒ 同样被缩了 5.73×。

**第三条（形状，且不依赖任何数值）**：
`yrs` 是**年份数**。若入参全是年率，则输出**不应随 `yrs` 变**。
⇒ 「输出随 `yrs` 变化」不是「它是年化」的证据（第 3.3 节）。

## 2. 入参口径审计（决定幂是否有资格存在的前提）

`x**(1/yrs)` 只在入参是**整段累计收益率**时正确。
若入参**已经是年率**，那个幂就是把年量再年化一次。

### 2.1 三个生产调用点传的都是**年率**（程序化取证）

| 调用点 | 入参 | 其来源与「它是年」的证据 |
|---|---|---|
| `measure_basket_nav_01.py:313` `req = required_excess(TARGET, c_mkt, yrs)` | `c_mkt` | 产物自报来源 `gap_to_target_by_benchmark.equal_weight.c_mkt_source` = `market_nav_caliber.json:equal_weight.geometric_annual_pct / 100.0` —— **除以 100 就是「它是百分数」的声明，而字段名里的 `geometric_annual_pct` 声明它是年率**（产物字段，JSON 路径见 §3.1） |
| 同上 | `TARGET` | `measure_basket_nav_01.py` 模块常量 `0.20` = 年目标 20% |
| `bench_seed_sweep.py:146` `req = {k: required_excess(target, c_mkts[k], yrs) …}` | `c_mkts[k]` | 该文件 `:91-92` 的 `geometric_annual(series, dates) -> (compounded_final_multiple, geometric_annual_fraction, n_days)`，第二项**就是年化分数** |

### 2.2 「年率」这件事在**本仓自己的定义层**就被钉死了

`measure_basket_nav_01.py:60-91 tier()`：
```
cagr = (1.0 + total) ** (1.0 / years) - 1.0      # years = n / R
```
而 `:290 mc = rows[0]["cagr"]` 就是传给 `gap_to_target_by_benchmark` 的那条腿。
⇒ **入参来自一个已经是 `(1+total)**(1/years)−1` 的量。**

### 2.3 书（`chan_lines.txt:4389`）

> 「the **geometric mean** of a set of numbers … gives the average **compounded** rate of return」

⇒ 年化操作的合法对象是**一个期间的收益率集合**。
对一个**已经是几何均值**的数再取几何均值，不是年化，是二次年化。

### 2.4 守卫自己传的入参也是年率

`tests/test_basket_nav_01_verdict.py:222` `T, cm, y = 0.20, 0.0995, 5.717`
—— 三个都是年率（5.717 是年份数，不是收益率）。

⇒ **全部六个调用点（3 生产 + 3 测试）传的都是年率。**
**「它没坏」的那条路（入参是整段累计）被证据封死，不是被偏好封死。**
