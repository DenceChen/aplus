# `net_nav_cost_tiers` 的变异规格（2026-10-16 新增）

规格本体在 `test_net_nav_cost_tiers.mut`；这里只放说明。

## 🚨 一条被**证伪**的变异：N8 曾是等价变异体

第一版 N8 写的是

```
N8 空序列也收进 net_by_cost（下游拿到 None）
    if daily is not None and len(daily):   →   if True:
```

它**存活**（`rc=0 / 10 passed`）。**「存活」有四种解释**，而这一条是第四种：

| 解释 | 下一步动作 |
|---|---|
| 守卫是安慰剂 | 去改守卫 |
| 变异没打中判据 | 去改规格的锚点 |
| 变异没落进文件 | 去查写盘与 sha256 |
| **变异与原实现等价** | **换掉这条变异，守卫一个字都不动** |

⚠️ **这四种在台子输出里逐位同形**（第 149 层已登记，本段是同一族的第二次）。

### 等价性的**四条前提**（全部程序取证，不是推理）

| # | 前提 | 取证结果 |
|---|---|---|
| 1 | 变异体真的落进文件 | `old` 命中 **1** 处；残留 `if True:` 命中 **0** 处 |
| 2 | `None` 到不了落盘 | chunk 的 DictComp 过滤条件是 `ser is not None and len(ser)` |
| 3 | 没有第三个消费者 | 全仓 `net_by_cost` 共 7 处引用，消费点只有 `.get(tag)`（`run_year`）与上面那个 DictComp |
| 4 | `_daily` 不返回**空 Series** | `_daily_series` 的 5 个 `return`：`None`×3、`daily`×1、元组×1，而 `daily` 之前有 `if not len(daily): return None` |

⇒ `_daily` 的返回值集合 ⊆ `{None, 非空 Series}`，两个分支逐一比对：

- **非空分支**：两侧都写 `out[tag] = 同一对象` ⇒ 一致；
- **`None` 分支**：变异体多出一个 `key → None`，而
  `.get(tag)` 对「缺键」与「有键但为 None」**返回同一个值**，
  chunk 的过滤器又把它剔掉 ⇒ 一致。

⇒ **可证等价。** 这不是「守卫没牙」，是**这条变异什么也没改**。

★ 探针本身在这一步翻了**两次车**（`DictComp` 的 `.key` 不是 `.keys`；
按 `key`/`value` 找都找不到——key 是变量 `tag`，value 里只有 `ser`）。
两次都差点被读成「前提 2 不成立」。⇒ **「查不到」与「不存在」不是同一句话**
（第 153 层）；正确姿势是先确认查询真跑过、定位条件对准了那一项。

### 为什么**不该**给守卫补断言来「杀掉」它

守卫此刻是对的。要让 N8 变红，只能加一条「`out` 里不许有 `None` 值」的断言——
那是**为了消灭一个等价变异而给生产代码加约束**：`_daily` 合法地返回 `None`，
而**下一个**下游若改成 `net_by_cost[tag]`（而不是 `.get`），这条新断言就会替它挡住。

⇒ 收益是零（今天的两个消费者已经对 `None` 免疫），
   代价是**一条恒真断言**（过严的守卫与恒真的一样有害，第 112 层），
   而**失效方向正是最贵的那个**：把一条正在工作的守卫改坏。

### 换成了什么

新 N8 打在同一函数的**循环**上——那一行至今没有任何变异覆盖过：

```
for tag in COST_TIER_TAGS:      →      for tag in COST_TIER_TAGS[:1]:
```

缺陷形态是真实的：`COST_TIER_TAGS` 加了第三档而循环只走前 N 档 ⇒
产物**少一列**而三档并排的版面**看不出任何区别**（本仓第 5 种形状的族）。
被 `test_the_rate_that_flows_into_the_net_series_is_the_declared_one` 杀掉。
