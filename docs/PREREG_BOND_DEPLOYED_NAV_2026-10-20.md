## 1. 口径定义（全部在看到数据前定死）

### 1.1 整手与成交额单位

| 量 | 值 | 出处/理由 |

| 股票 1 手 | 100 股 | `data/reports/portfolio_exec.json::lot_shares = 100` |

### 1.2 费用口径（**不另造成本模型**）

| 项 | 值 | 出处 |
|---|---|---|
| **主口径** | `cost = 0.003`（万 15/边 × **双边**） | `aplus/bond_horizon.py::COST_WAN15`；纸面账户 `bond_paper_state.json::cost = 0.003`；回测 `aplus/bond_excess.py::DEFAULT_COST` |

### 1.3 🚨 ¥5 最低佣金对转债是否适用（自问自答，写死结论）

- **适用**：A 股券商对**基金/债券/可转债**交易同样按「佣金、最低 ¥5/笔」收取；
  多数券商的转债佣金费率在**万 0.5~万 3**，但**最低 ¥5** 的门槛照样在。
- **转债没有印花税**（印花税 0.05% 只在股票卖出侧）——`aplus/costs.py` 的 docstring
  已逐字写明这一点，并说明 `bond_horizon` 的口径是**照股票侧对齐的、不是照转债**。
- **本仓成本模型不含 ¥5 固定佣金**（`aplus/costs.py::annual_friction` 是股票口径，
  且转债侧 `COST_WAN15` 是费率口径、无固定额）。
- **实测换算（5 万 / 10 只，每只 ¥5,000）**：
  - 最低佣金口径：单边 `max(¥5,000 × 0.03%, ¥5) = ¥5` ⇒ **0.10%/边** ⇒ 往返 **0.20%**
  - 本仓主口径：0.15%/边 ⇒ 往返 **0.30%**
  - ⇒ **主口径比「¥5 最低佣金 + 无印花税」口径高 1.5× ⇒ 本产物的成本是偏保守的一侧。**
- ⇒ **结论（写死）**：主口径**不改**；本产物**不另造成本模型**；
  上面的换算只作为**口径说明**随行，**不产生第二个判决臂**。
  ⚠️ 「更便宜的成本」属于**对转债有利**的方向，若将来用它放宽结论，
  必须**先预注册**（第 91 层：看到数据后改判据 = 自欺）。

| 常数 | 值 | 出处 | 本产物的用法 |
|---|---|---|---|
| **R = 244** | `aplus/hurdle.py::DAYS_PER_YEAR` | A 股实况 | **判决口径的唯一年化常数**（与股票侧 `basket_nav_01` 同一把尺子） |
| 252 | `aplus/verify.py::TRADING_DAYS_PER_YEAR` | 美股惯例 | **不用**。理由逐字抄自 `basket_nav_01::caliber.R_is_not`：「两者不是同一个量，本读数与 `verify.compounded_stats` 的 cagr 不可并排比较」 |
| 250 | `aplus/bond_horizon.py::TRADING_DAYS_PER_YEAR` | 转债侧历史口径 | **只作对照**：旧产物 `bond_excess_analysis.json::segments.*.strategy_ann` 用的是它 ⇒ 逐位对拍时用它 |

### 1.5 CAGR / MDE / 上界 / 符号可定性（**公式写死**）

```
日收益序列 r（长度 n）→ log1p(r)
累计总收益 total   = prod(1+r) − 1
years              = n / R                      （R = 244）
账户级几何 CAGR   c = (1+total)^(1/years) − 1   （total ≤ −1 时 c = None）
年化 MDE（逐日）  M_daily = 1.96 × sd(log1p r, ddof=1) / sqrt(n) × R
年化 MDE（分块）  M_block = 1.96 × sd(log1p 期收益, ddof=1) / sqrt(n_periods) × (R / hold_days)
95% 上界          U = c + M
符号可定性         measured_sign_determinable = (|c| ≥ M)
```

**为什么 `M_daily` 与 `M_block` 是同一个量（不是两个口径）**：
`sd(日) / sqrt(n_days) × R` 与 `sd(期) / sqrt(n_periods) × (R/h)` 在
`sd(期) = sd(日) × sqrt(h)` 时**恒等**。两个数并列是为了：
① 逐日口径**与股票侧 22.6738% 同一把尺子**（可比）；
② 分块口径的**观测单位 = 一次调仓**，是本仓自认的诚实口径
（`CLAUDE.md`：「K 日调仓时真实独立观测只有 n/K，分块 t 才是诚实的那一个」）。

⚠️ **逐日口径假设日内独立**，而本策略每 5 天才调一次仓 ⇒ 逐日收益**序列相关** ⇒
逐日口径的 SE **偏乐观**（偏小）。⇒ **判决用分块口径**（观测单位 = 一次调仓），
逐日口径**只作与股票侧的同尺对照**。⚠️ 若两个口径在「符号是否可定」上**不一致**，
**两个都写出来，不许挑一个**（第 91 层：看完数据再挑判据 = 自欺）。

### 1.6 「离 20% 差多少」

`gap_to_target_pp = (0.20 − c) × 100`，**但只有 `c` 本身可定符号时才有意义**。
`|c| < M` ⇒ **不许**把它读成「差多少」——见 §4。

## 4. 判决规则（**四条，抄 `scripts/measure_basket_nav_01.py::judge` 的语义**）

设 `c` = 账户级几何 CAGR，`M` = 年化 MDE，`T = 20%`，`U = c + M`：

| 条件 | 判决措辞（**逐字沿用仓内口径**） |
|---|---|
| `\|c\| < M` | 🚨 **连符号都定不了**（不可测的点估计只支持形状陈述） |
| `U < T` | 「在 95% 置信下**不可达**」 |
| `c < T ≤ U` | 🚨 **「测不出」**：**既不许说「达不到」，也不许说「接近」** |
| `c ≥ T` | 不许写「能做到」（转账户净值口径） |

**外加一条结构性闸门（写在最前，先于上面四条）**：
`years < 1.0` ⇒ **样本过短，不给方向**（抄 `portfolio_nav.json` 的既有口径：
「样本过短，不给方向（years=… < 1.0）」）。⇒ 前瞻臂（7 天 / years≈0.0287）**必然**落在这一档。

**「不许把『测不出』写成『没有』」**（硬约束）：任何一档的措辞都不得出现
「没有超额 / 没有 alpha / 证明无效 / 不存在」这类**水平陈述**；
只允许「测不出 / 连符号都定不了 / 与 0 不可区分」这类**测量陈述**。

### 5.4 长窗口·5 万可交付档（判决臂）

- 起点：`run_rotation` 给出的**同一批 picks、同一网格、同一期界**（不改选券）。
- 买入：期首后的第一个交易日的**开盘价**；每只按 `floor(每份预算 / (10 × 开盘价))` 手取整。
- 卖出：每只债**自身第 h 根 K 线的收盘**（与生产引擎 `_horizon_return_np` 逐位同义）；
  数据先于 h 根结束时按末根收盘（摘牌/强赎代理，与生产一致）。
- 成本：生产引擎的**同一换手公式**（按期加性扣）。
- 闲置现金：计 0（判决）+ 1.5%/年（敏感性）。
- 逐日序列：按同一记账口径的**逐日渲染**（用于 sd 与回撤），复利终点须与按期口径逐位相同（自检）。

## 6. 失败分支（先写死，跑到就照做）

### 6.1 缺字段 / 缺文件 ⇒ **报错，不回落**

- parquet 缺 `nav` / `cost_paid` / `holdings` 等必需列 ⇒ **抛异常**；
  **不许** `.get(col, 0)`、不许 `fillna(0)`、不许跳过该臂。
- 旧产物 `bond_excess_analysis.json` 缺 `segments.test` ⇒ **抛异常**。
- 股票侧参照产物缺 `tiers[1].cagr` ⇒ **抛异常**（不许自己算一个股票数来凑）。

### 6.2 逐位对拍失败 ⇒ **拒绝出数**

- 整手模拟器的分数极限 ≠ `run_rotation` 的逐期毛收益 ⇒ 抛异常，整个脚本 rc≠0，
  **不落盘**。理由：分叉的整手模拟器会把「口径不同」伪装成「整手影响」。

### 6.3 既有产物不可复现 ⇒ **照实说，不换产物、不改判据**

- 已观测事实（动笔前实测，**逐字记录**）：
  用**同一份生产代码**（`aplus.bond_excess.run_rotation`，参数 top_n=10 / h=5 / cost=0.003）
  跑**今日的转债主库**，得到的三段策略累计收益与
  `data/reports/bond_excess_analysis.json`（sidecar `stamped_at = 2026-10-16T22:59:18+00:00`）
  **不等**（段数、期数、天数三项全同 ⇒ **网格与窗口同，变的是收益**）。
  机制：日��锚 `110076.SH` 的首根 K 线从 2024-02-26 变成 2024-02-28
  ⇒ **整个调仓网格平移了 2 个交易日** ⇒ 长窗口数字整体改变。
- ⇒ 处置（写死）：
  ① 本产物的**主数字一律用今日数据重算**（可复现、随本产物盖章）；
  ② 旧产物的数字**逐字引用**并标注「2026-10-16 旧产物，**今日不可复现**」；
  ③ **不许**因为旧产物好看就用旧产物当判决臂，**也不许**因为旧产物难看就删掉它；
  ④ 网格平移的幅度**必须**与 `bond_paper_state.json::note` 披露的相位带
     **+6.8%~+17.1%** 一起报（若落在带内，说明这次变动就是相位效应，不是新发现）。

### 6.4 锚点保护失败 ⇒ 抛异常
