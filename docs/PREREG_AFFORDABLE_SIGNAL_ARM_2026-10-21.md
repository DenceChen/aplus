## §1 要问的问题

> **把「买得起」这件事拉进选股，毛超额掉多少？部署率升多少？**

⇒ 若毛超额**掉得少**而部署率**升得多** ⇒ ⇒ **这是一条真杠杆**
（账户年化 = 部署率 × 篮子收益 ⇒ 两者相乘）。
⇒ 若毛超额**塌得比部署率涨得多** ⇒ ⇒ **这条杠杆是负的**（和「部署率」那条一样）。

| 量 | 来源 | 用途 |

**判决链（顺序不许改，MDE 闸先判）**：

1. `|长腿毛超额| < MDE` ⇒ `POWERLESS`（**「测不到」**，**不是**「无效」）
2. `长腿毛超额 ≤ −D1 摩擦` ⇒ `SIG_NOT_DELIVERABLE`（**连摩擦都抵不过**）
3. `0 < 长腿毛超额 < D2 所需` ⇒ `POSITIVE_BUT_SHORT`（**方向对了但不够**）
4. `长腿毛超额 ≥ D2 所需` ⇒ `DELIVERABLE`（**这才是杠杆**）

**族级标签 = 逐格分布 + 计数**（过线格数 / 各态计数）⇒ **不许取极值**（不许写「最高/最低 t」）。

**干预臂的判决（B vs A，同 K）**：

| 情形 | 判决 |
|---|---|
| B 的毛超额 ≥ A 的毛超额（**同 K，逐位读**）**且** B 的部署率 > A 的 | `LEVER_WORTH_MEASURING`（⇒ 值得再走一次账户腿） |
| B 的毛超额 < A **且** 部署率的增益抵不过毛超额的损失 | `TRADE_OFF_NO_VERDICT` |
| B 的毛超额 < A 且 两者都在 MDE 之内 | `POWERLESS`（**测不到**，不是「没有」） |
| C 臂（负控）没有变差 | `INVALID`（**整套作废**） |
| D 臂（bm）没复现 | `INVALID`（**整套作废**） |

⚠️ **「部署率增益抵不过毛超额损失」必须用同一个尺子算**：
⇒ 比较**账户层的乘积**（部署率 × 篮子收益），不是两个数比大小（两个数**不是同一个量**）。
