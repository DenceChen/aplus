# 口径：目标 20% 是**净值**，判决量是**超额**（2026-10-15 预注册）

> **本文写在看到任何基准数字之前。** 下面 §4 的判据在测量跑出来之前就已写死；
> 若事后发现门槛需要改动，**必须杀掉进程、先改这一节、再重跑**（第 91 层）。

## §0 一句话

用户的目标是**账户净值年化 20%**。
全仓的判决量是**年毛超额**，而 `aplus/hurdle.py::hurdle_rate` 把「净值」直接写成了「超额门槛」，
**恒等式里少了基准项**。两个量的关系是

```
账户净值 = 基准 + 超额 − 摩擦
```

而 `hurdle_rate` 用的是

```
净 = 毛超额 − 年成本          ⇒   毛超额 = target + rounds × cost
```

⚠️ 第二式**当基准 = 0 时才成立**。基准若年化 +10%，正确的毛超额门槛是
`0.20 − 0.10 + 成本`，比现在算出来的**低整整一个基准的量**。

## §1 病灶在哪（代码事实，不是推断）

`aplus/hurdle.py::hurdle_rate` 的 docstring 逐字写着：

> 达到 ``target`` **净值**所需的**年毛超额**。
> 净 = 毛超额 − 年成本 ⇒ 毛超额 = target + rounds × cost

**同一个 docstring 里，分子写着「净值」、分母写着「超额」，中间那步没写基准。**

三个独立来源确认判决落在**毛超额**上：

| 位置 | 原文 |
|---|---|
| `aplus/hurdle.py::hurdle_rate` | 「净 = 毛超额 − 年成本」 |
| `scripts/cap_weighted_benchmark.py:238` | 「净口径只作对照：判决落在**毛**超额上（预注册 §2）」 |
| `data/reports/cap_weighted_benchmark.json` → `what_this_cannot_prove` | 「不能证明 20%/年（5 万本金 N=10 需 ≥26.41% **毛超额**）」 |

⇒ **这不是某处算错，是目标的定义被换掉了。**
判「能不能达到 20%」和判「能不能拿到 20% 超额」是两件事，
而**用户的目标字面上是后者之外的那件事**。

## §2 书怎么说（动手前先 grep 书的义务）

石川**把两个量明确并列过**：

- `data/books/cn_factor_lines.txt:565`「α 代表资产相对于某基准的超额收益」
- `:571`「市场指数就是基准，而因子投资的目标是使用不同的因子获得比市场收益率更高的收[益]」
- `:14026`「在主动投资中，通常把全市场指数或者某个宽基指数的收益率选为基准」

⇒ **「因子有效/无效」用超额判** —— 这一条书是支持的，仓库现有的因子判决**不必改**。

但同一本书在 `:9877`–`:9878` 把两个量并排列出：

> 表 5.10 至表 5.13 分别展示了不同投资组合的**绝对收益**以及**超额收益**的检验结果。

⇒ **书从没说过「目标 20%」必须以超额计**。
「用超额衡量因子」与「用净值衡量用户的目标」**可以并存**，仓库把它们合并成了一个。

## §3 现在缺的那个数

要把净值算出来，必须先有**基准自己在判决窗口上的复利收益**。当前状态：

| 来源 | 说的是 | 能不能引用 |
|---|---|---|
| `data/reports/market_benchmark_audit.json` | `filtered_annual = 0.0997` / `raw_annual = 0.0896` | ❌ **无 sidecar ⇒ `unknown`**；且窗口是 `['2019-01-02','2023-12-31']`，**不是判决窗口** |
| `scripts/audit_report_contamination.py:6` 的散文 | 「真实约 **+16%**」 | ❌ 散文；与上面那份产物的 **9.97%** 对不上，且 **+16% 不在任何产物里** |
| `scripts/cap_weighted_benchmark.json` | 只给**差**（组合 − 基准），不给基准自身 | ✅ 可引用，但它答不了这个问题 |

⇒ **判决窗口 `2021-01-01 → 2026-10-12` 上基准自身的复利收益，从未被测量过。**
⇒ 这是本预注册要做的第一件事，且**必须先有它，才谈得上改不改判据**。

### 🚨 §3.1 那句「+16%」为什么对不上（**已量化，处置：不删**）

`audit_report_contamination.py` 的 docstring 写着「修复前基准年化约 −126%，真实约 **+16%**」。
但它自己产的产物说：

| 量 | 值 |
|---|---|
| `raw_annual` | **0.08960184326869554** |
| `filtered_annual` | **0.09968156841721312** |
| `gap_annual` | −0.010079725148517585 |
| `paired_t` | **−1.8255962118084785** |
| `verdict` | 「污染不显著（t=−1.83，\|gap\| < 噪声）——原口径可留，但需记录」 |

**两个原因，方向相反，都指向「那两个数问的不是同一件事」：**

1. **窗口不同**：产物是 `['2019-01-02','2023-12-31']`（1154 天），
   而判决窗口是 `2021-01-01 → 2026-10-12`。**换窗口就不是同一个数**（第 7 种形状）。
2. **量的种类不同（更根本）**：docstring 问「**污染把基准改了多少**」
   （修复前 vs 修复后的基准**绝对水平**）；
   产物测的是「**上市前股票对日均收益的影响**」（**配对残差**），
   判决是「污染不显著」。
   ⇒ 产物**从来没有答过** docstring 那个问题。
   而 `+16%` **不出现在任何产物里** —— 它是一个**没有落盘的数**。

⚠️ **处置：不删那句话、不改那句 docstring。**
理由是第 25 层：那句话本身是**发现当时的证据**，
而删掉它会让「曾经以为基准是 +16%」这件事连痕迹都不留。
⇒ 正确处置是**在它旁边**写清它答不了这个问题，
而不是把它删掉或改小（第 92 层：中文散文被损坏也专挑注释）。

⇒ 顺带一条**通则**：
**「同一件事的两个数」经常是「两个不同的量各算了一次」。**
`+126%` 与 `+9.97%` 差得离谱，看上去像其中一个算错了；
实际是**一个在问绝对水平、另一个在问残差**，压根不该相等。
⇒ 所以发现差异时**第一反应不该是「有个数错了」**，
而是「这两个数问的是同一件事吗」（第 7 种形状的升级形态：
**连「是不是同一个量」本身都要问一遍**）。

## §4 预注册的判据（**在测量之前写死**）

### G1 —— 要测的量

在判决窗口 `2021-01-01 → 2026-10-12`（与 `cap_weighted_benchmark.json` 的
`window_arg` **逐字相同**）上，按**生产完全相同的口径**测基准的复利净值终值：

- 同一函数 `aplus.backtest._market_by_day`（不新写一条基准路径 —— 第 22 层）
- 同一抽样 `random.Random(42)` / `MARKET_SAMPLE = 150`
- 同一 `entry_lag = ENTRY_LAG = 1`
- 同一后复权（`factors_map`）
- 同一样本池：窗口内**每一个交易日**都要有一个基准收益，不许抽样日期

### G2 —— 口径标签是**必填**，不是可选

产物里必须能读到：这个数是**几何（复利）**还是算术，
以及它是**等权基准**还是**市值加权基准**。两者都要报，因为
`cap_weighted_benchmark.json` 已经证明两条基准在 2021–2026 差 **8.04pp/年**。

### G3 —— 判决规则（**先写死**）

| 若基准复利年化 | 则 |
|---|---|
| `> 0` | 现有 26.39% 门槛**偏高**（偏高量 = 基准年化）。净值口径的毛超额门槛 = `0.20 − 基准年化 + 成本`。**现有五档毛超额须按新门槛重判** |
| `= 0` | 现有判据成立，本预注册只作记录，不改任何数 |
| `< 0` | 现有门槛**偏低**，结论只会更严 —— 仍须记录，因为「更严」也是判决 |

⚠️ **只有 `> 0` 这一支会改变判决。** 另外两支不许顺手改数。

### G4 —— 不许做的事（在 G1 出数之前）

1. ❌ **不许改 `aplus/hurdle.py` 的任何一个字。** 它有 **8 个消费者**
   （`width_capital_feasibility` / `factor_width_mde` / `verdict_monthly_hurdle` /
   `backtest_walk_forward_weights` / `verdict_composite` / `ic_to_return` / `evolve_race` …），
   全仓判决都挂在它上面 ⇒ **必须先有可引用的基准数，再谈改法**。
2. ❌ **不许把门槛下调当成「达标」。** 门槛降低 = 目标降低，
   这是本仓第 129 层「降 K 是提速不是达标」的同族。
   净值口径若让结论翻面，那是**修正一个目标定义**，
   不是**找到一个能赚钱的办法** —— 两者的区别必须在产物里写清。
3. ❌ **不许用「毛超额口径更严所以更安全」把它糊过去。** 用户要的是净值，
   严的判据回答不了「我的钱会不会涨」。

### G5 —— 判据本身必须可被推翻

测量方法本身要过外部锚，否则就是第 22 层（两台测量仪）：

- 基准复利净值与**同期等权全池直接复利**（不走抽样）逐档比对，
  抽样 150/5460 带来的偏差必须**报出数字**。
- 两条臂（等权 / 市值加权）**都必须报**，不只报一条。

## §5 与既有结论的关系（**先说清哪些不受影响**）

| 结论 | 是否受影响 | 理由 |
|---|---|---|
| **因子判决**（`NO_LEVER` / `NO_SINGLE_FACTOR` / 逐因子 IC） | **不受影响** | 因子有效性按书的口径就是超额（§2） |
| **MDE / 显著性**（`factor_width_mde.json`） | **不受影响** | 测的是超额的噪声，不含基准 |
| **成本**（`costs.annual_friction`、4.787% 下界） | **不受影响** | 摩擦与基准无关 |
| **`0/6 年够线`**（K 扫描判决） | ⚠️ **可能受影响** | `hit_threshold` 直接比 `hurdle_rate()` |
| **「没有任何本金能达标」** | ⚠️ **可能受影响** | 同上（`width_capital_feasibility`） |

⚠️ 后两条是**当前最响的两句结论**。
若 G3 落在 `> 0` 一支，它们**都要重判**。
⇒ **在 G1 出数之前，这两句不得被当作最终结论引用。**
