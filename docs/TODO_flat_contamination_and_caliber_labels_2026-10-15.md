## 二、源码（逐字，非推算）

```python
# aplus/verify.py:26-27    判定路径 —— 认出 0.0 是特殊值
if actual_pct == 0:
    return "flat"

# aplus/verify.py:236,240  均值路径 —— 不认
up_net = ((up["actual_pct"] - up["cost"]) if "cost" in up.columns
          else up["actual_pct"])
avg_up = float(up_net.mean()) if n_up else 0.0

# aplus/verify.py:243      同理
avg_down = float(down["actual_pct"].mean()) if n_down else 0.0
```

⚠️ `n_up = up_net.notna().sum()`（`:238`）、`n_down = down["actual_pct"].notna().sum()`（`:239`）
——**`notna()` 对 `0.0` 返回 `True`。**
⇒ 守卫（有效成分数）**看不见** `flat`。

## 三、这不是假设：仓库自己记着同类事故

`aplus/verify.py:229-234` 逐字：

> 「`.mean()` 默认跳过 NaN，所以「篮子平均收益」可能只由**一只**股票构成——而调用方
> 完全看不出来。2026-10-11 实测：某日跌篮子 10 只里 9 只没有次日 bar
> （退市/长期停牌），`.mean()` 静默按剩下的 1 只计算，再被日度汇总平均，
> **多空价差虚报到 +9.84%**。」

落地：`verify.py:19 MIN_BASKET = 3`、`:398 daily = daily[size >= MIN_BASKET]`。

★★★ **⇒ 那次事故是 `NaN` 那一半，`MIN_BASKET` 也只管 `NaN`。
`flat`（`0.0`）这一半从未被覆盖——它长得像一个有效的数，所以躲过了以 `notna()` 为锚的守卫。**

## 九、更正版（2026-10-15 自查，**推翻第二节至第七节的成因判断**）

### 9.1 被证伪的那一步

初版断言：「`JUDGEABLE` 排除 `flat` ⇒ **判定层已裁定它不是有效观测**；
而均值层把它当真实零收益计入 ⇒ 两路径裁定相反。」

★ **错在把 `flat` 读成了「缺失态」。** 源码逐字（`aplus/verify.py:169-170`）：

```python
# 判定用毛值：成本是摩擦，不是方向信息。扣掉成本再判会把
# 「恰好平盘」判成 miss，等于用手续费凭空造出方向判断。
out["actual_pct"] = out["gross_pct"]
out["result"] = out.apply(lambda row: judge(row, row["gross_pct"]), axis=1)
```

⇒ **`flat` 是 `judge()` 有意设计的第三态：「恰好平盘」，不是「没量到」。**
⇒ 它被 `JUDGEABLE` 排除的**理由**是「平盘既不算对也不算错」，
**不是**「数据不可用」。
⇒ **均值层把它计入，在「篮子平均收益」口径下是正确的。**
⇒ **⇒ 初版的核心指控不成立，撤回。**

⚠️ 推论：初版 F1（用 `is_valid()` 替换 `notna()`）与 F3（把 `flat` 归一为 `no_data`）
**会把平盘误当缺失**，同样撤回。

### 9.2 仍然站得住的缺陷：两个分母并列报出，且差异未报

| 口径 | 分母定义 | 实测值 |
|---|---|---|
| 命中率（`hit_rate_up` / `_down` / `overall`） | `result.isin(("hit","miss"))` ⇒ **排除 `flat` 与 `no_data`** | `judged = 89` |
| 均值（`avg_up` / `avg_down`） | `.notna()` ⇒ **只排除 `no_data`，计入 `flat`** | `n_down = 47`、`n_up = 45` |

⚠️ **同一个 `flat`，一处被排除、一处被计入；
`judged = 89` 与 `n_down = 47` / `n_up = 45` 并列出现在同一张表里，
而 `stats.json` 的任何字段都没说明这个差异。**

★ **这才是可辩护的断言，且它与成因无关**：

⚠️ **本文件不断言哪个口径对。**
